# Dzaleka Online Services

A community platform for Dzaleka Refugee Camp, providing information about services, events, news, and resources.

## Tech Stack

- **Framework**: [Astro](https://astro.build/)
- **Styling**: Tailwind CSS
- **Deployment**: Netlify
- **Email**: Resend
- **Forms**: Formspree

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
