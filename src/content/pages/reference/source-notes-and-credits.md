# Source notes and credits

This site mixes original community publishing with adapted reporting, archive material, and public reference documents.

## When a source note appears

- A source note is used when a page is adapted from an outside article, report, or public document.
- The note should name the original source and make it clear that the page is an adaptation, not a straight copy.
- A source note is not meant to replace proper linking. Where possible, the original source should still be linked.

## How adapted content is handled

- External reporting should be rewritten for this site instead of pasted in full.
- The rewritten version should keep the key facts, dates, and attributions that matter to readers.
- If a claim cannot be verified clearly enough, it should be removed or softened rather than dressed up with vague language.

## Photo credits

- Photo credits should stay visible on stories, galleries, and image-led pages.
- If an image comes from an external photographer or publication, the credit should stay with the image or caption.
- If image rights are unclear, the safer choice is to link to the source or remove the image until the rights are clearer.

## Fixing mistakes

- If a source note is wrong, incomplete, or missing, use [Contact](/contact) or [Help Desk](/help-desk) to flag it.
- If an image credit needs correction, include the page link and the correct credit details.
