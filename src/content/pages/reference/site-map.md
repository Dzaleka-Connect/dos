# Site map

Use this page when you are not sure where to start.

## Start with the urgent and practical pages

- Go to [Get help now](/get-help-now) if the issue is urgent, unsafe, or time-sensitive.
- Go to [New to Dzaleka](/new-to-dzaleka) if you have recently arrived and need the first practical steps.
- Go to [Languages](/languages) if you need help finding information in simpler English or through community language support.
- Go to [Easy Read](/easy-read) if you want shorter, simpler pages.

## Find services and rights

- Use [Services](/services) to look for organisations, schools, support groups, and community services.
- Use [Rights Navigator](/rights-navigator) for legal guidance, protection topics, and reporting routes.
- Use [Help Desk](/help-desk) for general support requests that are not urgent.

## Find opportunities and community activity

- Use [Jobs](/jobs) for vacancies and job notices.
- Use [Skills Exchange](/skills-exchange) to offer or request practical skills.
- Use [Grants and Programs](/grants-and-programs) for funding and programme opportunities.
- Use [Events](/events) for upcoming community events and public activities.

## Read, watch, and explore

- Use [News](/news) for announcements and reporting.
- Use [Updates](/updates) for product and platform changes.
- Use [Stories](/stories) for photo essays and longer community reporting.
- Use [Photos](/photos) for image collections and contributor work.
- Use [Resources](/resources) for reports, guides, and reference documents.

## Site and developer reference

- Use [Docs](/docs) for site guides and contributor help.
- Use [API Docs](/api-docs) for the public API, discovery routes, and examples.
- Use [Open Data Platform](/open-data-platform) for public data access.

If you still do not know where to go, use [Search](/search).
